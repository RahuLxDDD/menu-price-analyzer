# Menu Price Analyzer

Standalone restaurant menu pricing decision-support tool.

## MVP
- Upload dine-in/base menu as CSV/XLS/XLSX
- Upload current Zomato pricing export as CSV/XLS/XLSX
- Fuzzy item matching with variant safeguards
- Compare dine-in vs current online price
- Commercial inputs: commission, PG, GST on commission, discount, Ads/CV, Growmax/promo
- Target payout and max uplift controls
- Recommended Zomato price with 9/5/0 endings
- KEEP / INCREASE / DECREASE / UNMATCHED actions
- Export Zomato-ready CSV while preserving original Zomato row fields and IDs

## Planned
- PDF and image dine-in menu extraction
- Better R/M/L and pieces/portion parsing
- Manual match review UI
- Category-aware pricing rules
- Restaurant summary and merchant-facing report

> Decision-support only. Review recommendations before publishing prices.
